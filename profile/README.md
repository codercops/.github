### 🏆 Monthly contributor leaderboard

Every month has its own [leaderboard](https://oss.codercops.com/leaderboard). It counts merged PRs labeled `codercops-accepted` across our four repos, and the top 5 get a shout-out on our X and LinkedIn pages. Everyone on it gets a card to share. Only PRs for issues that were assigned to you count, and the full rules (AI tools, spam, reviews) are in each repo's CONTRIBUTING.md.

Good places to start:

- **OGCOPS:** new template ideas are in [#5](https://github.com/codercops/ogcops/issues/5).
- **toolbelt:** build a whole new tool from the [`new tool`](https://github.com/codercops/toolbelt/issues?q=is%3Aissue+is%3Aopen+label%3A%22new+tool%22) issues.
- **ChatCops** and **discord-bot:** see the [`good first issue`](https://github.com/search?q=org%3Acodercops+label%3A%22good+first+issue%22+state%3Aopen+no%3Aassignee&type=issues) list.

Thanks to everyone who took part in CODERCOPS October 2026. The [final results](https://oss.codercops.com/leaderboard/2026-10) stay online. Contributors who keep showing up can become maintainers, see [GOVERNANCE.md](https://github.com/codercops/.github/blob/main/GOVERNANCE.md).

### 🤝 Join the Community

We welcome contributors of all skill levels! Here's how to get involved:

1. **Find an issue** — Look for [`good first issue`](https://github.com/search?q=org%3Acodercops+label%3A%22good+first+issue%22+state%3Aopen&type=issues) or [`help wanted`](https://github.com/search?q=org%3Acodercops+label%3A%22help+wanted%22+state%3Aopen&type=issues) labels across our repos
2. **Fork & contribute** — All public repos are open for contributions via pull requests
3. **Join discussions** — Share ideas, ask questions, or show what you've built in [Discussions](https://github.com/codercops/codercops-discussions/discussions)
4. **Chat on Discord:** ask questions and meet other contributors on our [Discord server](https://discord.gg/mpGdJyjaRQ). Issue claims still happen on GitHub.
5. **Become a member:** once you have a merged PR, you can [**request to join CODERCOPS**](https://github.com/codercops/.github/issues/new?template=join-request.yml). A maintainer reviews every request.

### Ways to Contribute

- **Code** — Bug fixes, new features, performance improvements
- **Templates** — Design new OG image templates for OGCOPS (great first contribution!)
- **Documentation** — Improve READMEs, guides, and API docs
- **Testing** — Report bugs, write tests, improve coverage
- **Ideas** — Suggest features and improvements via issues or discussions
